# Clientify

### One mod. All your essentials.

Clientify combines many of Minecraft's most popular **PvP, HUD, and quality-of-life features**
into a single lightweight mod.

Instead of installing separate mods for Keystrokes, Armour HUD, Potion Effects, Ping, Zoom,
Waypoints, Coordinates, and more, everything is available through one editor and one unified
appearance system.

**Fabric • Minecraft 1.21.11 • Client-side only**

---

## Features

<details>
<summary>HUD Modules</summary>

| Module | What it does |
| --- | --- |
| **Action Bar** | Move, scale and restyle the action bar text. |
| **Armor HUD** | Worn armour and its durability, pieces placeable separately. |
| **Boss Bar** | Move, scale, recolour or hide boss bars. |
| **Coordinates** | Position, direction and biome, coords moveable separately. |
| **Custom Text** | Any text you like, anywhere, as many lines as you want. |
| **Effects HUD** | Active potion effects with timers, and blink or colour change as they run out. |
| **FPS** | Your framerate on the HUD. |
| **Item Counter** | Counts any chosen item from your inventory. |
| **Keystrokes** | Movement keys and mouse buttons as you press them, with CPS and press animations. |
| **Nametags** | Nametag scale, background, shadow and whether you see your own. |
| **Ping** | Your measured ping to the server. |
| **Reach Display** | How far away your last hit landed. |
| **Saturation** | Your hidden saturation as text, an overlay or a bar. |
| **Scoreboard** | The sidebar, moved and restyled with your own font and backgrounds. |
| **Sprint Indicator** | Your sprint and movement state, including flying and gliding. |
| **Tab List** | Tab list tweaks: header, footer, heads, ping display and colours. |
| **Title** | Move, scale and restyle server titles. |

</details>

## Powerful HUD Editor

Press **Right Shift** to open the editor.

- Drag modules anywhere on screen
- Resize with the mouse wheel
- Snap to screen centre and nearby modules
- Move precisely with arrow keys
- Configure every module individually

No config files. No commands. Everything is done in-game.

---

## Fully Customisable

Create a setup that matches your style.

- Multiple profiles
- Custom fonts
- Rounded backgrounds
- Blur effects
- Borders and shadows
- Custom colours
- Chroma mode
- Gradients
- Gradient waves
- Apply one style to every module instantly

Every module follows the same appearance system, making it easy to create a clean and consistent UI.

---

## Server Friendly

No unfair-advantage modules.

Clientify is built around HUD customisation, visual improvements, and quality-of-life features that
work on virtually any server without affecting gameplay.

---

## Installation

1. Install Fabric Loader
2. Install Fabric API
3. Place Clientify into your `mods` folder
4. Launch Minecraft

---

## Building

```
gradlew build
```

The release jar is `build/libs/clientify-<version>+<mcversion>.jar` — ignore the `-sources` one.
